# 2026-11-25 4번 시연 설명과 계약서 조회 확인

작업일: 2026-11-25. 브랜치: `feat/4-ai-contract`.

AI 단가 분석은 사람이 화면에 금액을 적는 것이 아니라, 저장된 프로젝트 설명을 읽습니다. 아래 세 글은 그 설명 칸에 그대로 붙여 넣는 시연용입니다. 결과물이 여러 개라서 기능이 나뉘기 쉽고, 금액이나 출력 모양을 시키지는 않습니다.

이 컴퓨터에는 `OPENAI_API_KEY` 가 없습니다. 그래서 아래 글로 모델이 견적을 만든 화면은 확인하지 못했습니다. 시연 당일에는 서버 환경 변수로 그 키가 있어야 결과 화면이 나옵니다.

## 1. 동네 빵집 픽업 예약

```text
동네 빵집 사장님이 전화 주문 대신 쓸 작은 예약 페이지를 원합니다. 손님은 인기 메뉴 네 개를 사진과 짧은 소개로 보고, 빵 이름과 수량을 고른 뒤 픽업 날짜와 시간을 고릅니다. 주문할 때는 이름과 휴대폰 번호만 받습니다. 회원 가입은 없습니다. 사장님은 들어온 주문을 목록으로 보고, 빵이 준비되면 준비 완료로 표시합니다. 준비 완료가 되면 손님 화면의 주문 상태가 준비 완료로 바뀝니다. 결제는 넣지 않습니다. 손님은 가게에서 픽업할 때 계산합니다.
```

이 글 안의 결과물은 메뉴 소개, 수량과 픽업 시간 선택, 주문자 연락처, 사장님 주문 목록, 준비 완료 표시입니다.

## 2. 학원 수업 신청

```text
초등학교 앞 영어 학원이 수업 신청을 받습니다. 학부모는 학년별 수업 목록에서 요일과 시간을 보고, 아이 이름과 연락처를 남겨 신청합니다. 정원이 찬 수업은 신청 버튼이 막혀야 합니다. 원장님은 신청 목록을 보고 확정 또는 대기로 나눕니다. 확정되면 학부모 화면에 첫 수업 날짜가 다시 보입니다. 강사 소개는 이름, 담당 학년, 짧은 경력만 있으면 됩니다. 동영상 강의와 숙제 채점은 이번 범위에 없습니다.
```

이 글 안의 결과물은 학년별 수업 목록, 신청 입력, 정원 마감, 확정과 대기 나누기, 강사 소개입니다.

## 3. 도자기 공방 작품 소개

```text
도자기 공방이 작품 열 점을 소개하는 페이지를 원합니다. 방문자는 작품마다 사진, 크기, 만드는 데 걸린 기간, 남은 수량을 봅니다. 마음에 드는 작품은 문의 한 장으로 이름, 연락처, 원하는 수량을 보냅니다. 사장님은 문의를 읽은 뒤 답장 완료로 표시합니다. 첫 화면에는 이번 달 작업 일정과 공방 위치가 있습니다. 온라인 결제, 회원 등급, 장바구니는 넣지 않습니다.
```

이 글 안의 결과물은 작품 목록, 작품 상세, 문의 보내기, 답장 완료 표시, 일정과 위치 안내입니다.

## 다른 계정으로 남의 계약서가 보이는지

팀 공용 데이터베이스 접속 정보는 이 컴퓨터에 없습니다. 시연 계정으로 로그인하지는 못했습니다. 회원, 프로젝트, 지원 표는 이번 확인에 필요한 칸만 임시로 만들었고, 계약 표와 조회 규칙은 저장소의 `0400_ai_estimates.sql`, `0401_contracts.sql` 을 그대로 실행했습니다. 데이터베이스는 이 컴퓨터의 PostgreSQL 17이고, 확인이 끝난 뒤 지웠습니다.

표 주인은 조회 규칙을 통과하므로, 숫자는 일반 로그인 역할에서만 세었습니다. 계약은 두 건입니다. 갑은 의뢰인 A와 프리랜서 B의 서명 중인 계약이고 금액은 1,500,000원입니다. 을은 의뢰인 C와 프리랜서 D의 서명이 끝난 계약이고 금액은 800,000원입니다.

| 확인한 일 | 결과 |
| --- | --- |
| 규칙을 적용하기 전, 표 주인이 센 계약 | 2건 |
| 의뢰인 A가 계약을 본다 | 1건. 금액은 1,500,000원만 보입니다 |
| 프리랜서 B가 계약을 본다 | 1건 |
| 의뢰인 C가 A의 프로젝트 계약을 본다 | 0건 |
| 의뢰인 C가 계약을 본다 | 1건. 금액은 800,000원만 보입니다 |
| 프리랜서 D가 A의 프로젝트 계약을 본다 | 0건 |
| 프리랜서 D가 계약을 본다 | 1건 |
| 로그인하지 않은 역할이 계약을 본다 | 표를 열 권한이 없어 거절됩니다. 목록이 나오지 않습니다 |
| 의뢰인 A를 탈퇴 처리한 뒤 A가 본다 | 0건 |
| 그 뒤에도 프리랜서 B가 본다 | 1건 |

조회 규칙은 계정이 살아 있고, 그 계약의 의뢰인이거나 프리랜서일 때만 행을 보여 줍니다. 다른 의뢰인과 다른 프리랜서에게는 남의 계약 금액이 나오지 않았습니다.
