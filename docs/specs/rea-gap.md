# 위시켓 공개 화면 기준, 아직 없는 기능

작성: 2026-11-27 (한국시간)

로그인하지 않고 위시켓 메인과 프로젝트 찾기만 다시 대조했습니다. 로그인 뒤 화면은 보지 않았습니다. 문구와 디자인은 가져오지 않았습니다.

이미 있는 화면(가입, 프로젝트, 지원, 알림, 참고 견적, 계약, 결제, 리뷰)은 여기 넣지 않습니다. 공용 데이터베이스에는 2026-11-27에 ERD의 외래키를 연결했습니다.

## 1. 검색 대상을 고르지 못함

위시켓 프로젝트 찾기는 검색 대상을 전체, 제목, 관련 기술, 프로젝트 내용 중에서 고릅니다.

우리 검색은 `0202_project_search.sql`에서 제목과 설명만 봅니다. 기술은 검색어가 아니라 필터로만 고릅니다. 기술 이름만 검색하는 선택은 없습니다.

## 2. 지원이 적은 순 정렬이 없음

위시켓 정렬에는 금액이 높은 순, 지원이 적은 순, 최신 등록 순, 마감 임박 순이 있습니다.

우리 정렬은 최신순, 마감 임박순, 예산순입니다. 지원자 수가 적은 프로젝트를 위로 올리는 정렬은 없습니다. 지원자 수는 카드에 표시만 합니다.

## 3. 기간제 프로젝트와 근무 조건이 없음

위시켓은 외주(도급)와 기간제(상주)를 나눕니다. 기간제에는 역할, 레벨, 경력 범위, 월 금액, 근무 시작일, 근무 위치가 있습니다. 외주에는 클라이언트 위치가 있습니다.

우리 `projects`는 외주 한 종류입니다. 위치, 역할, 레벨, 월 금액 칸이 없습니다.

## 4. 필터 저장이 없음

위시켓은 로그인 뒤에 필터 이름과 조건을 저장합니다. 우리는 주소의 검색 조건만 유지하고, 저장해 두는 표가 없습니다.

## 5. 유사 사례 검색이 없음

위시켓 메인에는 만들고 싶은 것을 문장으로 넣으면 비슷한 사례를 찾는 입력이 있습니다.

우리는 그 문장으로 참고 견적(`ai_estimates`)만 만듭니다. 기존 프로젝트나 포트폴리오를 비슷한 순으로 보여 주는 기능은 없습니다.

## 6. 파트너 찾기와 등급이 없음

위시켓 공개 메뉴에는 파트너 찾기와 파트너 등급이 있습니다. 우리는 공개 프로필의 분야, 기술, 경력, 시간당 금액만 있습니다. 파트너 목록 화면과 등급 칸은 없습니다.

## 7. 포트폴리오 작품 목록이 없음

위시켓은 작품마다 제목, 담당 범위, 플랫폼, 기술 태그가 있는 목록을 보여 줍니다. 우리는 `profiles.portfolio_url` 주소 한 칸만 있습니다.
