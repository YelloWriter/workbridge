# 유저 플로우에서 비거나 막히는 기능

작성: 2026-11-27 (한국시간)

의뢰인과 지원자(프리랜서)가 등록부터 리뷰까지 가는 길을 현재 화면 기준으로 다시 따라가 봤습니다. 위시켓은 파트너 계정으로 로그인한 뒤 보이는 메뉴만 구조로 확인했습니다. 문구와 디자인은 가져오지 않았습니다.

이미 이슈로 있는 일(알림 종, 리뷰 자리, 납품 버튼, 검색·정렬·기간제·필터 저장·유사 사례·파트너·작품 목록)은 여기서 다시 만들지 않습니다.

## 1. 우리 시나리오 안에서 막히는 곳

의뢰인 길: 프로젝트 등록 → 지원자 선정 → 계약 서명 → 결제 → 완료 승인 → 리뷰

지원자 길: 프로젝트 찾기 → 지원 → 금액 동의 → 서명 → 납품 요청 → 리뷰

| 구간 | 지금 | 막히는 점 |
| --- | --- | --- |
| 의뢰인, 계약으로 가기 | 지원자 관리 화면에 계약 목록 링크가 있습니다. | 위 메뉴에 계약이 없습니다. 그 화면을 벗어나면 계약서를 다시 찾기 어렵습니다. |
| 지원자, 계약으로 가기 | 수락된 지원에만 계약 목록 링크가 있습니다. | 위 메뉴에 계약이 없습니다. |
| 체결 뒤 결제 | 양쪽 서명이 끝난 계약서에 결제 링크가 있습니다. | 위 메뉴에 결제 내역이 없습니다. 계약서를 열어야만 결제로 갑니다. |
| 납품과 완료 승인 | 버튼 컴포넌트는 있습니다. | 계약서에 아직 끼우지 않았습니다. 이 구간은 이슈 #46입니다. |
| 알림으로 다음 단계 알기 | 알림 페이지는 있습니다. | 위 메뉴의 알림 자리는 비어 있습니다. 이 구간은 이슈 #8입니다. |

## 2. 위시켓 로그인 뒤에만 보였고, 우리 시나리오에 없는 기능

### 2.1 미팅

파트너 메뉴는 지원 다음에 미팅 예정, 계약 여부 논의, 계약 체결 실패로 나뉩니다. 우리는 지원 수락 뒤에 바로 금액 동의와 서명으로 갑니다. 미팅 약속, 결과, 불발 상태가 없습니다.

### 2.2 의뢰인의 지원 요청

파트너 메뉴에 의뢰인이 먼저 보내는 지원 요청이 있습니다. 마감되면 목록에서 빠집니다. 우리는 지원자가 프로젝트에 지원하는 방향만 있습니다.

### 2.3 알림 분류

알림이 전체, 프로젝트 문의, 계약 논의, 프로젝트 기록, 받은 평가로 나뉩니다. 우리는 알림을 한 목록으로만 보여 줍니다. 종류 값은 이미 `notifications.type`에 있습니다.

### 2.4 프로필의 학력, 자격, 수상

파트너 프로필에 소개, 기술, 경력 외에 학력, 자격증, 수상, 작품 목록이 섹션으로 있습니다. 작품 목록은 이슈 #62입니다. 학력, 자격, 수상은 우리 `profiles`에 칸이 없습니다.

## 3. 이번 문서에서 만들지 않는 것

신원 인증, 도장 이미지, 간편 날인은 이번 주 계약 범위 밖입니다. 의뢰인 전용 등록 화면은 이 파트너 계정으로 열리지 않아 새로 적지 않습니다. 우리 의뢰인 등록은 `/projects/new`에 있습니다.
