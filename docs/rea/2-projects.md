# REA: 위시켓 프로젝트 등록·탐색 (2번 담당 범위)

- 분석 대상: 위시켓(wishket.com)의 **로그인 없이 보이는 공개 화면**만. 로그인 후 화면은 분석하지 않음.
- 확인한 날: 2026-11-23
- 원칙: 화면 흐름과 기능 구조(항목 이름)만 기록한다. 디자인·문구·이미지는 옮기지 않는다. (CLAUDE.md 10번)
- 프로젝트 상세 화면은 별도 주소(`project.wishket.com`)에 있다. 외주 1건, 기간제 1건을 로그인 없이 열어 확인했다. **비로그인 상태에서는 상세 내용 대부분이 잠겨 있어**, 4장은 "보이는 부분 + 잠긴 항목 이름"까지만 적었다.

## 1. 메인 화면 (`/`)

위에서 아래 순서:

1. 맨 위 얇은 안내 띠: 담당 매니저 소개 + 기간제 프로젝트 희망 시작일 등록 유도 (프리랜서 대상)
2. 헤더 메뉴: 프로젝트 등록 / 프로젝트 찾기 / 파트너스 찾기 / 이용방법 / 포트폴리오 / 비즈니스 솔루션 / 로그인 / 회원가입
3. 첫 화면 소개 영역: 서비스 소개 + 버튼 2개 ("매칭 시작", "견적 상담 신청")
4. 신뢰 숫자 4~5개: 방문자 수, 프리랜서 수, 개발 회사 수, 누적 프로젝트 금액, 만족도
5. 서비스 분야 바로가기 8개: IT 서비스 / 업무 시스템 / 웹사이트 / AI / 커머스 / 클라우드 / 컨설팅 / 유지보수
6. "유사사례 검색 AI" 입력 영역: 만들고 싶은 것을 문장으로 입력, 예시 질문 3개 제공
7. 포트폴리오 영역: 분야 탭(AI, 중개플랫폼, 커머스·쇼핑몰, 홈페이지, 앱, ERP·CRM, LMS, 기타) + 카드 여러 개
   - 포트폴리오 카드 정보: 제목, 담당 범위(개발·디자인·기획), 플랫폼(웹/앱 등), 기술 태그, "플러스" 표시

참고: 메인에는 **프로젝트 검색창이 따로 없다.** 검색은 `프로젝트 찾기` 화면에 있다. 메인의 입력창은 AI 유사사례 검색용이다.

## 2. 프로젝트 찾기 목록 (`/project/`)

### 2-1. 화면 구성 (위 → 아래)
1. 상담 유도 배너 여러 개 (무료 견적 상담, 프로젝트 등록 유도 등)
2. 검색창 + **검색 대상 선택**: 전체 / 제목 / 관련 기술 / 프로젝트 내용
3. 계약 형태 탭: **외주(도급)** — 프로젝트 단위로 금액 지급 / **기간제(상주)** — 월 단위로 금액 지급 (탭마다 필터 항목이 다름)
4. 필터 영역 (아래 2-2) + 필터 초기화 + 필터 저장(로그인해야 가능)
5. 결과 줄: "N개의 프로젝트" (확인 시점 67,232개) + "모집 마감 제외" 토글 + 정렬 선택
6. 프로젝트 카드 목록 (아래 2-4)
7. 페이지 번호 이동 (1, 2, 3 … 번호 방식)

### 2-2. 필터 종류

**외주(도급) 탭**
| 필터 | 선택 방식 |
| --- | --- |
| 업무 범위(카테고리) | 개발 / 디자인 / 기획 중 복수 선택, "선택한 카테고리만 보기" 옵션 |
| 프로젝트 분야 | 웹 / PC 프로그램 / 안드로이드 / 임베디드 / iOS / 기타 중 복수 선택, "선택한 분야만 보기" 옵션 |
| 서비스 종류 | 약 70개 항목 복수 선택 (예: IT 서비스 구축, 웹사이트 제작, 중개·매칭 플랫폼, SaaS·솔루션 …) |
| 예상 금액 | 최소~최대 범위 |
| 예상 기간 | 일 단위 최소~최대 |
| 예상 시작일 | 날짜 범위 + 초기화 |
| 진행 분류 | 신규 프로젝트 / 리뉴얼·유지보수 |
| 클라이언트 위치 | 시·도 → 시·군·구 단계 선택 |
| 기술 스택 | 알파벳(A~Z) 인덱스로 찾는 기술 목록, 약 250개 복수 선택 |

**기간제(상주) 탭**
| 필터 | 선택 방식 |
| --- | --- |
| 역할(직무) | 개발 / 디자인 / 기획 아래 약 50개 직무 복수 선택 (풀스택, 백엔드, 프론트엔드, UI/UX 기획자 등) |
| 필요 레벨 | 주니어 / 미드 레벨 / 시니어 / 테크 리드 / 디렉터 (각 레벨 설명 제공) |
| 경력 | "N년 이상 ~ N년 이하" 범위 |
| 기술 스택 | 외주 탭과 같은 기술 목록 |
| 근무 시작일 | 날짜 범위 |
| 월 금액 | 범위 |
| 예상 기간 | 범위 |
| 근무 위치 | 시·도 → 시·군·구, 해외, 재택 근무, 주차 가능 |
| 산업 분야 | 서비스업, 금융·은행업, IT·정보통신업, 판매·유통업, 제조·생산·화학업, 교육업, 의료·제약업, 미디어·광고업, 문화·예술·디자인업, 건설업, 기관·협회 |
| 프로젝트 유형 | SI / SM |

| 클라이언트 인력 상황 | 협업 가능한 인력 있음 |

**공통 (클라이언트 신뢰 필터):** 평가 우수 / 인증 완료
**필터 도구:** 선택한 필터 개수 표시, "N개의 프로젝트 보기" 버튼, 필터 초기화, 필터 저장(로그인 필요)

### 2-3. 정렬
기본 정렬 순 / 금액 높은 순 / 지원 적은 순 / 최신 등록 순 / 마감 임박 순
+ "모집 마감 제외" 토글 (기본 켜짐으로 보임)

### 2-4. 카드 1개에 보이는 정보

| 구분 | 항목 |
| --- | --- |
| 공통 | 모집 상태 라벨(모집 중), 새 글 표시(NEW), 제목, 금액, 예상 기간(일), 기술 태그, 지역, 등록일자, 마감까지 남은 기간, 지원자 수, 조회 수준 표시("높음"/"아주 높음"), 이 프로젝트를 관심 프로젝트로 담은 파트너 수 |

- 카드를 누르면 상세로 이동. 상세 주소 형태: `project.wishket.com/project/<번호>/`

## 3. 프로젝트 등록 진입 흐름 (`/project/add/` → `/project/create/`)

로그인 전에 보이는 첫 화면만 확인했다.

1. 헤더의 "프로젝트 등록" 또는 목록의 등록 유도 버튼 → 등록 화면으로 이동
2. **계약 형태 선택 2가지:** 외주(만들고 싶은 서비스·결과물이 있다) / 기간제(프리랜서를 채용하고 싶다)
3. 버튼: "다음", "이 단계 건너뛰기", "견적 상담 신청"
4. 하단 도움말 4종: 예산 작성이 어려운 경우 / 내용 작성이 어려운 경우 / 처음 이용하는 경우 / 마음에 드는 파트너를 발견한 경우
5. "다음" 이후의 입력 화면은 열어보지 않았다.

## 4. 프로젝트 상세 화면

주소 형태: `project.wishket.com/project/<번호>/`. 외주 1건·기간제 1건을 비로그인으로 열어 확인했다.

### 4-1. 화면 구성 (위 → 아래)
1. **머리 영역:** 모집 상태 라벨, 계약 형태 라벨(외주/기간제), 등록일자, 제목, 모집 마감일 + 마감까지 남은 기간
2. **탭 3개:** 프로젝트 상세 / 기업 상세 / 산업 상세 (기업·산업 상세는 로그인해야 보임)
3. **핵심 요약 박스** (아래 4-2)
4. **본문 섹션** (아래 4-3)
5. **지원 영역:** 마감까지 남은 기간, "프로젝트 지원하기" 버튼, 지원자 수 (비로그인이면 로그인 안내)
6. **유사 프로젝트:** 목록 카드와 비슷한 작은 카드 여러 개 (상태, 계약 형태, 제목, 금액, 기간, 시작일, 직무·레벨, 지역)
7. 옆/위쪽에 "유사사례 검색 AI" 유도와 "등록한 프로젝트는 매니저 상담 후 공개" 안내

### 4-2. 핵심 요약 박스에 보이는 항목
| 계약 형태 | 항목 |
| --- | --- |
| 외주 | 카테고리(개발 등), 플랫폼(웹/안드로이드/iOS/PC), 서비스 종류 태그, 예상 금액, 예상 기간, 예상 시작일, 필수 기술(태그), 핵심 과업 |
| 기간제 | 직무, 레벨, 경력 범위(예: 7~20년 차), 월 예상 금액, 근무 시작일, 예상 기간, 근무 위치, 기술별 요구 경력 범위(예: "2~15년") |

### 4-3. 본문 섹션 (제목만 기록)
- 외주: 업무 내용 / 진행 고려 사항 / 미팅 / 사전 검증 질문 / 핵심 과업 / 필수 기술 / 수행·협업 조건
- 기간제: 업무 내용 / 근무 환경 / 모집 요건 / 사전 검증 질문 / 구인 정보
- **사전 검증 질문:** 지원서를 쓸 때 클라이언트가 낸 질문에 답하는 방식. 질문 내용은 로그인해야 보임.

### 4-4. 비로그인 상태에서 가려지는 것
업무 내용 일부, 진행 고려 사항, 미팅, 사전 검증 질문, 핵심 과업, 수행·협업 조건, 근무 환경, 모집 요건, 기업 상세, 산업 상세는 "로그인하고 확인하세요" 안내로 대체된다. 제목, 금액, 기간, 기술, 마감일, 지원자 수 등 요약 정보는 로그인 없이 보인다.

### 4-5. 북마크 관련
- 목록 카드에는 "관심 프로젝트로 추가한 파트너 수"가 보인다. (북마크에 해당하는 기능)
- 비로그인 상세 화면에서는 북마크 버튼 자체를 확인하지 못했다. (로그인 후에만 보이는 것으로 추정되나, 로그인 후 화면은 분석 대상이 아니므로 확인하지 않음)
