# 3번 공개 페이지 조사 — 지원과 알림

- 조사일: 2026-11-23 (월), 한국 시간
- 대상: wishket.com의 비로그인 공개 프로젝트 상세와 공식 고객센터·이용 가이드
- REA 저장소: https://github.com/morluto/rea
- 도구 확인: 이 세션에 REA MCP 및 `rea` CLI가 연결되어 있지 않았다. 공식 저장소 안내는 읽었으며, 사용자 지시에 따라 브라우저와 웹 열람으로 대체했다. **REA 실행 결과가 아니다.** 에이전트 설정 변경이나 전역 설치는 하지 않았다.
- 로그인·가입·지원서 제출은 하지 않았다. 잠긴 본문을 우회하거나 내부 API·개인정보를 조사하지 않았다.

## 공개 자료로 확인하지 못한 것

- **지원 제출 직후 이동 주소**, 완료 화면의 내용과 버튼
- 현재 로그인 지원서 폼의 상세 구성, 저장·수정·취소 동작
- 현재 알림 종의 미확인 숫자 표현, 목록 정렬·읽음 처리·모두 읽음·실시간 갱신
- 위시켓의 자동 거절 조건과 지원자 선정 트랜잭션, 내부 DB 구조

위 항목을 위시켓에서 관찰한 사실로 기술하지 않는다. 로그인하지 않고 확인할 수 있는 범위를 넘어섰기 때문이다.

## WorkBridge에 반영하는 흐름

1. 프로젝트 상세에서 지원 페이지로 연결한다. 상세 버튼 삽입은 2번이 담당한다.
2. 로그인 확인 후 프로필이 미완성이면 프로필로 보낸다. 돌아올 주소를 보존한다.
3. 자기소개·예상 금액·예상 기간을 입력하고 제출한다.
4. 제출 성공 후 `/me/applications`로 이동한다. 이는 사용자 요구이며 위시켓의 관찰 결과가 아니다.
5. 의뢰인은 지원서를 검토하고 한 명을 수락하거나 직접 거절한다.
6. 수락·자동 거절·직접 거절·모집 마감 소식을 알림에서 확인한다. 종의 안 읽은 개수와 모두 읽음은 WorkBridge 요구에 따른 구현이다.

화면의 구성 원리만 참고한다. 위시켓의 로고·이미지·스타일·설명 문장은 가져오지 않았다. 문구와 UI는 WorkBridge 용도로 새로 작성했다.
